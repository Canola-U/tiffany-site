# Tiffany Room

SOOP `w96idqb`와 YouTube `@w96idqb`의 방송·영상 소식을 모아보는 팬 사이트입니다. Node.js 24 이상에서 외부 npm 의존성 없이 실행됩니다.

## 인터넷에 공개하기

[Render 배포 안내](DEPLOY.md)를 확인하세요. 상시 알림을 위한 유료 서버와 영구 저장공간을 구성하는 `render.yaml`이 포함되어 있습니다. 배포 계정 로그인과 요금 확인·서버 생성은 사용자가 해야 하며, 이 파일만으로 사이트가 배포되지는 않습니다.

## 빠른 시작

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm start
```

기본 포트는 3000입니다. `PORT`로 변경할 수 있습니다. 개발 모드는 `npm run dev`, 테스트는 `npm test`입니다. 클라우드 작업에서는 `/workspace/tiffany-site`에서 실행합니다. 각 작업은 이미 격리되므로 사용자가 요청하지 않는 한 별도 Git worktree를 만들지 않습니다. 최초 실행에는 API 키가 필요하지 않습니다. 외부 서비스 연결이 없어도 사이트와 원문 발췌·보관 기능은 실행됩니다.

로컬에서는 `.env.example`을 `.env`로 복사해 설정할 수 있습니다. 실제 토큰은 Git에 올리지 마세요. 클라우드에서는 환경 설정의 비밀값·환경 변수 입력을 사용하세요. 저장된 설정과 실행 중 환경은 다를 수 있습니다.

## 기능

- SOOP 방송 상태와 YouTube 최신 영상: 1분마다 확인. 조회 실패는 오프라인과 구별합니다.
- 디스코드 알림: 방송 시작과 RSS 안에서 새로 발견한 영상을 채널로 보냅니다.
- 브라우저 알림: 사이트를 열어둔 동안 동작하는 보조 알림입니다.
- 보관함: 북마크한 영상을 해당 브라우저에 저장합니다.
- 다시보기 요약: 자막을 입력하고 정리·저장·열기. AI 미연결 시 **원문 발췌**로 표시합니다.
- Windows 트레이 앱: 방송 시작 시 SOOP를 자동으로 엽니다. ZIP 다운로드를 제공합니다.

## 디스코드 연결

1. Discord Developer Portal에서 봇을 만들고 서버에 초대합니다. 대상 채널의 View Channel, Send Messages 권한이 필요합니다. Message Content Intent는 필요하지 않습니다.
2. `DISCORD_BOT_TOKEN`에 봇 토큰을 등록합니다. 플랫폼 프록시 비밀값의 허용 목적지는 `discord.com`입니다.
3. `DISCORD_CHANNEL_ID`에 알림 받을 채널 ID를 설정합니다. 현재 지정한 채널은 `1566736820396359711`입니다.
4. 서버를 계속 실행합니다. 최초 정상 조회는 기준점으로만 저장합니다. 이후 새로 감지한 방송·영상부터 발송합니다.

연결 오류는 방송 종료로 판단하지 않습니다. 디스코드 실패는 다음 1분 주기에 재시도합니다. 발송 기록은 `.data/delivery.json`에 저장해 중복을 줄입니다. 외부 발송 직후 프로세스가 중단되면 중복될 수 있습니다. 프로세스 중단 동안 발생한 이벤트의 완전한 수집은 보장하지 않으며 RSS의 최신 12개 범위에서 감지합니다. 재시작 시 이미 방송 중인 방송이나 기존 영상을 과거 알림으로 발송하지 않습니다.

## 외부 연결과 환경 변수

| 이름 | 용도 |
| --- | --- |
| `DISCORD_BOT_TOKEN` | 디스코드 알림용 비밀값 |
| `DISCORD_CHANNEL_ID` | 디스코드 대상 채널 ID |
| `YOUTUBE_CHANNEL_ID` | 선택: UC… 형태 채널 ID. 핸들 자동 검색 실패 시 설정 |
| `LLM_API_KEY` | 선택: OpenAI 요약용 비밀값. 없으면 원문 발췌 |
| `LLM_MODEL` | 선택: 기본값 gpt-4o-mini |
| `WRITE_TOKEN` | 공개 배포 시 요약 작성 보호용 비밀값 |
| `PORT` | 기본 3000 |
| `DATA_DIR` | 기본 .data. 영구 저장용 볼륨에 연결 가능 |

접근 목적지: `discord.com`, `www.youtube.com`, `i.ytimg.com`, `live.sooplive.com`. AI 요약에는 `api.openai.com`이 추가로 필요합니다. SOOP 및 YouTube 공개 피드·플레이어 API는 제공자 변경이나 제한이 있을 수 있어 실제 연동 확인이 필요합니다. 시작 스크립트의 `--use-env-proxy`는 플랫폼 프록시 인증 및 TLS 검증을 유지합니다.

## 다시보기 요약

제목, SOOP/YouTube HTTPS 영상 주소, 80~60,000자의 자막·대화록을 입력합니다. AI 키가 설정되면 입력 자막을 외부 AI 제공자에게 보내 한국어로 요약합니다. 사용할 권한이 있는 내용만 입력하세요. AI 응답 실패를 성공한 요약으로 표시하지 않습니다. AI 키가 없으면 원문의 최대 6개 문장을 발췌합니다. `.data/summaries.json`에 보관하며 새로고침 후에도 읽을 수 있습니다.

영상 URL만으로 자막 수집·오디오 다운로드·음성 인식을 자동 실행하지 않습니다. 이 자동화는 별도 구현과 제공자 접근 권한이 필요합니다.

## Windows 방송 자동 열기 앱

사이트의 알림·앱 설정 탭에서 ZIP을 내려받거나 GitHub의 `desktop/` 폴더를 받습니다. PowerShell에서 실제 사이트 주소로 설치합니다.

```powershell
.\install.ps1 -SiteUrl "https://실제-티파니룸-주소"
```

Windows 10/11 기본 PowerShell/.NET을 사용하는 트레이 앱입니다. 앱과 PC가 켜져 있는 동안 1분마다 확인합니다. 처음 실행할 때 이미 방송 중이면 바로 엽니다. 같은 방송은 앱 실행 중 한 번만 엽니다. Windows 로그인 시 자동 시작합니다. 자동 열기 끄기·종료는 트레이 메뉴에서 합니다. 재시작 시 자동 열기 설정은 다시 켜집니다. 제거 방법은 `desktop/README.txt`를 확인하세요.

Windows 실제 실행 검증 및 코드 서명은 아직 완료하지 않았습니다. EXE가 아닌 스크립트 앱입니다. macOS/모바일은 미지원입니다. 인터넷에서 접속 가능한 상시 실행 서버를 먼저 준비해야 합니다.

## API와 검증

- `GET /healthz`: 앱 실행 상태 (외부 서비스 응답과 독립)
- `GET /`: 대시보드 HTML
- `GET /api/status`: 실제 외부 서비스 조회 결과와 설정 유무. 토큰 값은 포함하지 않습니다.
- `GET /api/summaries`: 저장된 요약
- `POST /api/summaries`: 요약 생성·저장. WRITE_TOKEN 설정 시 Bearer 인증 필요
- `GET /downloads/tiffany-windows.zip`: Windows 앱 ZIP

`npm test`는 피드 파싱, 입력 검증, 알림 전이·중복 방지·재시도, Discord 요청 형식, HTTP 요약 작성·권한·영구 저장·동시 요청을 검증합니다. 외부 서비스는 모의 응답으로 검증하며 실제 디스코드 발송이나 AI 연동 성공을 의미하지 않습니다.

## 배포 전 확인

클라우드 환경 **게시**는 개발 환경의 스냅샷 저장입니다. 사이트를 인터넷에 배포하거나 24시간 실행하는 것과 다릅니다. 공개 서비스에는 HTTPS, 지속 실행 프로세스, 영구 데이터 볼륨과 백업이 필요합니다. `NODE_ENV=production`에서 `WRITE_TOKEN`이 없으면 요약 작성이 차단됩니다. 작성 키가 있어도 사용자별 계정·사용량 제한은 별도 구현이 필요합니다. 데이터 저장은 단일 서버용이며 여러 프로세스의 동시 쓰기는 지원하지 않습니다.
